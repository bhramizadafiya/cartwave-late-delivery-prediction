# Raw Data Sources

The raw data used in this project comes from the Olist Brazilian E-Commerce Public Dataset.

Primary public source:
- https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Raw files used in this project:
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_customers_dataset.csv

For cloud-based preprocessing and training, the raw files were uploaded to Amazon S3 under the project bucket and loaded into the notebook environment from there.
